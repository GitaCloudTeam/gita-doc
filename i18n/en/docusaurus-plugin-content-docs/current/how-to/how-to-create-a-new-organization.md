# How to Create a New Organization?

1. In the GITA main panel, click on the highlighted button below, "**Create Organization**":
    > ![image](/images/image012.png)
    >
    > ***Image 01: Create Organization button in main panel***
2. Enter the desired name for the Organization in the highlighted field and press "**Create**":
    > ![image](/images/image013.png)
    >
    > ***Image 02: Screen - Create organization***
3. The user will be redirected to the organization's main page where they can add clusters for monitoring and a message indicating the success of the operation will be displayed in the bottom right corner.
    > ![image](/images/image014.png)
    >
    > ***Image 03: Screen - Organization's main panel***
