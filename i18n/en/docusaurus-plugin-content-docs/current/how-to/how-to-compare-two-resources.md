# How to Compare Two Resources?

1. Access your Cluster Interface on Gita:
    > ![image](/images/image160.png)
    >
    > ***Image 01: Panel - Cluster Selection***
    >
    > ![image](/images/image161.png)
    >
    > ***Image 02: Cluster Interface***

2. Click on the **Inventory** section on the left side of the Interface screen:
    > ![image](/images/image162.png)
    >
    > ***Image 03: Inventory Section***

3. Within the Inventory section, click on the **Workload** section:
    > ![image](/images/image163.png)
    >
    > ***Image 04: Workload Section***

4. In the Workload tab, select the type of resource you want to edit (for example: **Deployment**):
    > ![image](/images/image172.png)
    >
    > ***Image 05: Deployment Section***

5. Find and select the **<u>resource name</u>** you want to compare:
    > ![image](/images/image173.png)
    >
    > ***Image 06: View of Resources of the Selected Type in the Cluster***

6. Click on the **Compare** tab to compare two resources:
    > ![image](/images/image179.png)
    >
    > ***Image 07: Tab - Compare***

7. To select the resource you want to use as a comparison, select the cluster (**Select cluster…**) where the resource is located and fill in any other comparison filters you deem necessary: **Namespace** and/or **Search...** (image):
    > ![image](/images/image183.png)
    >
    > ***Image 08: Screen - Comparison Filters (filled)***

8. Find and select the desired resource:
    > ![image](/images/image184.png)
    >
    > ***Image 09: Resource Selection***

9. After selecting the resources to compare, view the comparison of the particular files side by side (**Side-by-side**) or as continuous text (**Inline**):
    >
    > ![image](/images/image185.png)
    > ***Image 10: Side-by-side View***
    >
    > ![image](/images/image186.png)
    > ***Image 11: Continuous Text View (Inline)***
