# How to Change a Cluster's Name?

1. Access the GITA interface and choose the cluster where you want to make the change.
    > ![image](/images/image135.png)
    >
    > ***Image 01: Screen - Organization's main panel***
2. In the left sidebar menu that will appear, under Cluster, navigate to the Configuration section and click on Settings.
    > ![image](/images/image136.png)
    >
    > ***Image 02: Screen - Cluster settings***
3. At the top of the page that will open, under General, locate the Change Cluster Information option. Find the text field identified as Cluster Name, edit the name as desired and click Save Changes.
    > ![image](/images/image137.png)
    >
    > ***Image 03: Screen - Settings panel***
