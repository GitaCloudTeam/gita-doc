# How to Edit a Resource?

1. Access your Cluster Interface on Gita:
    > ![image](/images/image160.png)
    >
    > ***Image 01: Panel - Cluster Selection***
    >
    > ![image](/images/image161.png)
    >
    > ***Image 02: Cluster Interface***

2. Click on the **Inventory** section on the left side of the Interface screen:
    > ![image](/images/image162.png)
    >
    > ***Image 03: Inventory Section***

3. Within the Inventory section, click on the **Workload** section:
    > ![image](/images/image163.png)
    >
    > ***Image 04: Workload Section***

4. In the Workload tab, select the type of resource you want to edit (for example: **Deployment**):
    > ![image](/images/image172.png)
    >
    > ***Image 05: Deployment Section***

5. Find and select the **<u>resource name</u>** you want to access:
    > ![image](/images/image173.png)
    >
    > ***Image 06: View of Resources of the Selected Type in the Cluster***

6. Click on the three vertical dots in the top right corner of the screen to view the available features for the selected resource:
    > ![image](/images/image178.png)
    >
    > ***Image 07: Feature Selection***

7. Find and select the **Edit Yaml** option to edit the selected resource:
    > ![image](/images/image174.png)
    >
    > ***Image 08: Option - Edit Yaml***

8. Edit the selected resource and then click the **Save** button to save the changes:
    > ![image](/images/image180.png)
    >
    > ***Image 09: Screen - Resource Edit View and Save Button***

9. Alternatively, you can click directly on the three dots to the right of the <u>resource name</u> and then on **Edit Yaml**, without needing to open it.
    > ![image](/images/image176.png)
    >
    > ***Image 10: Feature Selection***
    >
    > ![image](/images/image175.png)
    >
    > ***Image 11: Option - Edit Yaml***
