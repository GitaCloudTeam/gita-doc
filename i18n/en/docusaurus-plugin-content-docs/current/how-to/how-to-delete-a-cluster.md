# How to Delete a Cluster?

1. Access the GITA interface and choose the cluster you want to delete.
    > ![image](/images/image135.png)
    >
    > ***Image 01: Screen - Organization's main panel***
2. In the left side menu that will appear, under Cluster, navigate to the Settings section and click on Definitions.
    > ![image](/images/image136.png)
    >
    > ***Image 02: Screen - Organization's main panel***
3. Scroll down to the Advanced section.
    > ![image](/images/image138.png)
    >
    > ***Image 03: Screen - Settings panel, 'Advanced' highlighted***
4. Within the Advanced section, locate the Delete Cluster option. To delete the cluster, copy the command and execute it in your terminal to remove the cluster.
    > ![image](/images/image141.png)
    >
    > ***Image 04: Screen - Settings panel, 'Delete Cluster' highlighted***
5. After executing the command, return to the GITA interface and confirm the cluster deletion by clicking the Delete Cluster button.
    > ![image](/images/image142.png)
    >
    > ***Image 05: Screen - Settings panel, 'Command highlighted' from the organization***
6. A confirmation message will be displayed on the screen. Review the information, type the name of the cluster that will be deleted and confirm the action by clicking Delete.
    > ![image](/images/image143.png)
    >
    > ***Image 05: Dialog - Confirmation box***
7. The cluster will be deleted and can no longer be used.
