# How to Register On GITA?

1. Access the [GITA registration page](https://app.gita.cloud/register)
    > ![image](/images/image001.png)
    >
    > ***Image 01: New account screen on Gita***
2. Fill in the fields shown in the image above
3. Click on the **Sign Up** button, as shown below
    > ![image](/images/image002.png)
    >
    > ***Image 02: Registration button***
4. When clicking the button, an account validation link will be sent to the registered address. The user's screen will be redirected to the one shown in figure XXX.
5. On this screen, the user can request the system to resend the validation email by clicking the **Resend Link** button or return to the login screen with the **Back** button. As shown below
    > ![image](/images/image003.png)
    >
    > ***Image 03: Email validation screen***
6. In the provided email, the user must access the link sent by "**noreply@gita.cloud**" to validate the account.
7. When clicking the link, they will be redirected to the GITA initial panel, indicating that the operation was successful.
