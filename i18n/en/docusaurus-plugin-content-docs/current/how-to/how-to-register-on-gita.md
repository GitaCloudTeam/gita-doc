# How to register on GITA?

1. Access the [GITA registration page](https://app.gita.cloud/register)
    > ![image](/images/image001.png)
    >
    > ***Image 01: New account screen on GITA***
2. Fill in the fields shown in the image above.
3. Click the **Sign Up** button, as shown below
    > ![image](/images/image002.png)
    >
    > ***Image 02: Sign Up button***
4. When the button is pressed, a verification code will be sent to the registered email address. The user will be redirected to the verification screen.
5. In the informed email, the user must retrieve the code sent by "**noreply@gita.cloud**". To validate the account, use the generated code that was sent to the registered address to fill in the email verification field.
    > ![image](/images/image003.png)
    >
    > ***Image 03: Email verification screen***
6. On this screen, the user can also request the system to resend the verification code by pressing the **Resend Code** button, as shown below.
    > ![image](/images/image251.png)
    >
    > ***Image 04: Email verification screen - Resend Code button***
7. If the email verification field is filled in correctly, the user will be redirected to GITA's initial dashboard, indicating that the operation was successfully completed.
