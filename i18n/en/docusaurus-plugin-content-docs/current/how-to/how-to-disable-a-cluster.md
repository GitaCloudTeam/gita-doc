# How to Disable a Cluster?

1. Access the GITA interface and choose the cluster you want to disable.
    > ![image](/images/image135.png)
    >
    > ***Image 01: Screen - Organization's main panel***
2. In the left side menu that will appear, under Cluster, navigate to the Settings section and click on Definitions.
    > ![image](/images/image136.png)
    >
    > ***Image 02: Screen - Settings panel***
3. Scroll down to the Advanced section.
    > ![image](/images/image138.png)
    >
    > ***Image 03: Screen - Settings panel***
4. Within the Advanced section, locate the Disable Cluster option and click the corresponding button to disable the cluster.
    > ![image](/images/image139.png)
    >
    > ***Image 04: Screen - Organization's main panel***
5. A confirmation message will be displayed on the screen. Review the information, type the name of the cluster that will be disabled and confirm the action by clicking Disable.
    > ![image](/images/image140.png)
    >
    > ***Image 05: Dialog - Disable cluster***
6. The cluster will be disabled and recorded events will no longer be collected.
