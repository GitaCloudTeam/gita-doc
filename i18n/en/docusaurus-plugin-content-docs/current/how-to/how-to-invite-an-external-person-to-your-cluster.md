# How to Invite an External Person to Your Cluster?

1. From the home page (https://app.gita.cloud/home), click on a cluster from the organization you want to modify
   - Alternatively, use the search field in the top left corner, highlighted by the green rectangle in the image below
   > ![Figure 01](/images/image110.png)
   >
   > ***Image 01: Main panel - Cluster***
2. In the side menu, access **Configuration > Users**
   > ![Figure 02](/images/image111.png)
   >
   > ***Image 02: Main panel - Highlight 'Settings'***
3. In the top right corner, click on **Create Invite Link**
   > ![Figure 03](/images/image112.png)
   >
   > ***Image 03: Settings - Highlight 'Create Invite Link'***
4. Check the selection box of the cluster you want to share. The search field can be used to filter the listing. Note that it's possible to share access to multiple clusters at once, as long as they belong to the same organization
   > ![Figure 04](/images/image113.png)
   >
   > ***Image 04: Dialog box - Adding users to cluster***
5. Define the permission level that will be assigned to the external guest
   > ![Figure 05](/images/image114.png)
   >
   > ***Image 05: Dialog box - Permission definition***
6. Click on **Generate Link**
   > ![Figure 06](/images/image115.png)
   >
   > ***Image 06: Dialog box - Highlight 'Create Link'***
7. In the next window, copy the generated link by clicking **Copy Link**. The link is valid for 24 hours
   > ![Figure 07](/images/image116.png)
   >
   > ***Image 07: Dialog box - Generated link***
