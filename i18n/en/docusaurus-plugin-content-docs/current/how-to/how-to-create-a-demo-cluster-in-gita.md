# How to create a Demo Cluster in GITA?

## Creating a demo cluster in GITA allows users to explore and test the platform's features safely, without needing to connect a real cluster. It is ideal for learning, demonstrations, testing, and onboarding new users, providing a risk-free environment to get hands-on experience with GITA!

1. On the **Home** page of GITA, click the **Create Cluster Demo** button:
    > ![image](/images/image224.png)
    >
    > ***Image 01: Gita Home***

2. Name the demo cluster to be created as you prefer:
    > ![image](/images/image225.png)
    >
    > ***Image 02: Naming Tab for Demo Cluster***

3. Click **Create** and wait for the cluster creation to load, which may take a few minutes:
    > ![image](/images/image226.png)
    >
    > ***Image 03: Creation Button***
    >
    > ![image](/images/image227.png)
    >
    > ***Image 04: Demo Cluster Creation Loading***

4. Once the creation is complete, a confirmation message will appear on the screen, informing you until what time the demo cluster will be available - it will remain available for 3 hours after creation. Just click **Go to Cluster** to use the demo cluster:
    > ![image](/images/image228.png)
    >
    > ***Image 05: Creation Confirmation and Go to Cluster Button***
    >
    > The remaining usage time is shown at the top of the cluster screen:
    >
    > ![image](/images/image229.png)
    >
    > ***Image 06: Remaining Usage Time for Demo Cluster***
