# How to Change the Password?

1. In the GITA panel, select the settings menu (shown in the figure below), in the top right corner and, then, the option "**Edit profile**"
    > ![image](/images/image004.png)
    >
    > ***Image 01: Settings menu***
2. When accessing the option, the user will be taken to the screen below, where they should look for the "**Security**" option in the sidebar menu, as highlighted in the image below.
    > ![image](/images/image005.png)
    >
    > ***Image 02: Edit profile menu***
3. In the security tab, the user must fill in the fields shown in the figure below and then click on the "**Save**" button to register the change.
    > ![image](/images/image006.png)
    >
    > ***Image 03: Edit profile menu***
4. If the operation was completed successfully, a message indicating success will be displayed in the bottom right corner.
    > ![image](/images/image007.png)
    >
    > ***Image 04: Success message in password change***
