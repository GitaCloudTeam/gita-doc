# Memória insuficiente nos Nodes Kubernetes

Nodes Kubernetes exigem uma determinada quantidade de memória para executar de forma adequada cargas de trabalho e processos do sistema. Quando um node apresenta memória insuficiente (*Insufficient Memory*), ele pode entrar em um estado crítico, levando-o a degradar performance ou até mesmo rejeitar cargas de trabalho.

Pressão na memória frequentemente surge a partir de excesso de '*commits*', vazamento de memória ou uso de aplicações não otimizadas. Monitoramento e abordagem desses problemas são essenciais para manter a estabilidade e confiabilidade do cluster.

Para mitigar insuficiência de memória, certifique-se a alocação de recursos adequada e o monitoramento consistente do uso.

Para mais informações, visite a documentação do Kubernetes.
