# Como alterar o nome de uma organização

1. A partir da [página inicial](https://app.gita.cloud/home), clique em um cluster da organização que deseja alterar
   - Alternativamente, utilize o campo de busca no canto superior esquerdo, destacado com o retângulo verde na imagem abaixo
   > ![Figura 01](/images/image124.png)
   >
   > ***Imagem 01: Painel - Página principal***
2. No menu lateral, acesse **Settings > General**, no canto inferior esquerdo
   > ![Figura 02](/images/image125.png)
   >
   > ***Imagem 02: Painel - Destaque 'Configurações'***

   > ![Figura 03](/images/image126.png)
   >
   > ***Imagem 03: Configurações - Destaque 'General'***
3. Insira o nome desejado no campo **Organization name**
   > ![Figura 04](/images/image127.png)
   >
   > ***Imagem 04: Configurações - Destaque 'Organization Name'***
4. Clique em **Save** para confirmar a alteração
   > ![Figura 05](/images/image128.png)
   >
   > ***Imagem 05: Configurações - Destaque 'Save'***
