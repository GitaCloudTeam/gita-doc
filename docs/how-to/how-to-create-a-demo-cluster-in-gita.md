# Como criar um Cluster Demo no GITA?

## A criação de um cluster demo no GITA permite que o usuário explore e teste as funcionalidades da plataforma de forma segura, sem precisar conectar um cluster real. Ele é ideal para aprendizado, demonstrações, testes e onboarding de novos usuários, proporcionando um ambiente livre de riscos para conhecer o GITA na prática!

1. No **Home** do GITA, clique no botão **Create Cluster Demo**:
    > ![image](/images/image224.png)
    >
    > ***Imagem 01: Home Gita***

2. Nomeie o cluster demo a ser gerado de acordo com sua preferência:
    > ![image](/images/image225.png)
    >
    > ***Imagem 02: Visualização - Aba de Nomeação do Cluster Demo***

3. Clique em **Create** e aguarde o carregamento da criação do cluster, pode levar alguns minutos:
    > ![image](/images/image226.png)
    >
    > ***Imagem 03: Visualização - Botão de Criação***
    >
    > ![image](/images/image227.png)
    >
    > ***Imagem 04: Visualização - Carregamento da Criação do Cluster Demo***

4. Assim que a criação for concluída, uma mensagem de confirmação será exibida na tela informando até que horário o cluster demo ficará disponível - ele ficará disponível por 3 horas após a criação. Basta clicar em **Go to Cluster** para utilizar o cluster demo:
    > ![image](/images/image228.png)
    >
    > ***Imagem 05: Visualização - Confirmação de Criação e Botão Go to Cluster***
    >
    > O tempo restante de uso é informado na parte superior da tela do cluster:
    >
    > ![image](/images/image229.png)
    >
    > ***Imagem 06: Visualização - Tempo Restante de Uso do Cluster Demo***
