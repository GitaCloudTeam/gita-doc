# Como convidar um usuário externo para o seu cluster

1. A partir da página inicial (https://app.gita.cloud/home), clique em um cluster da organização que deseja alterar
   - Alternativamente, utilize o campo de busca no canto superior esquerdo, destacado com o retângulo verde na imagem abaixo
   ![Figura 01](/images/image110.png)
2. No menu lateral, acesse **Configuration > Users**
   ![Figura 02](/images/image111.png)
3. No canto superior direito, clique em **Create Invite Link**
   ![Figura 03](/images/image112.png)
4. Marque a caixa de seleção do cluster que deseja compartilhar. O campo de busca pode ser utilizado para filtrar a listagem. Note que é possível compartilhar o acesso a múltiplos clusters de uma vez, desde que pertencentes à mesma organização
   ![Figura 04](/images/image113.png)
5. Defina o nível de permissão que será atribuído ao convidado externo
   ![Figura 05](/images/image114.png)
6. Clique em **Generate Link**
   ![Figura 06](/images/image115.png)
7. Na janela seguinte, copie o link gerado clicando em **Copy Link**. O link possui validade de 24 horas
   ![Figura 07](/images/image116.png)
