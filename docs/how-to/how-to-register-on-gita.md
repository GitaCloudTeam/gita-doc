# Como se registrar no GITA?

1. Acesse a [página de cadastro do GITA](https://app.gita.cloud/register)
    > ![image](/images/image001.png)
    >
    > ***Imagem 01: Tela de nova conta no Gita***
2. Preencha os campos exibidos na imagem acima.
3. Clique no botão **Sign Up**, conforme mostrado abaixoœ∑
    > ![image](/images/image002.png)
    >
    > ***Imagem 02: Botão de cadastro***
4. Ao acionar o botão, um código de verificação da conta será enviado para o endereço cadastrado. O usuário será redirecionado para a tela de validação.
5. No e-mail informado, o usuário deverá acessar o código enviado por "**noreply@gita.cloud**". Para validar a conta, utilize o código gerado que foi enviado ao endereço cadastrado para preencher o campo de validação do e-mail.
    > ![image](/images/image003.png)
    >
    > ***Imagem 03: Tela de validação do e-mail***
6. Nesta tela, o usuário também poderá solicitar que o sistema reenvie o código de verificação ao acionar o botão **Resend Code**, conforme mostrado abaixo.
    > ![image](/images/image251.png)
    >
    > ***Imagem 04: Tela de validação do e-mail - Botão Resend Code***
7. Se o campo de validação do email for preenchido corretamente, o usuário será redirecionado para o painel inicial do GITA, indicando que a operação foi concluída com sucesso.
