# How to Have an Overview of Pod Status Across the Cluster?

1. In the cluster's main panel, the user should look for the "**Details**" button (highlighted in the image below), within the "**Pods**" box:
    > ![image](/images/image024.png)
    >
    > ***Image 01: Screen - Gita main panel***
2. When entering the "**Details**" section, it will be possible to view all namespaces created in the cluster and, by accessing the arrows highlighted in the image below, all clusters that correspond to that namespace
    > ![image](/images/image025.png)
    >
    > ***Image 02: Screen - Namespace view***
3. Clicking on the highlighted arrow above, the user can view all pods, their states and their network connection:
    > ![image](/images/image026.png)
    >
    > ***Image 03: Screen - Pod details***
4. Clicking on a specific Pod, the user will be redirected to the view of that pod, viewing metrics, manifests, data graphs, etc.
    > ![image](/images/image027.png)
    >
    > ***Image 04: Screen - Pod detail***
